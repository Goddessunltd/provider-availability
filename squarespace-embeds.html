Squarespace — Available Now Embeds

One code snippet per provider. Paste each into a Squarespace Code Block on the provider's profile page. The badge only appears when that provider has marked themselves available in the app — nothing shows when they're not active.

How to use in Squarespace

  1. Enter your JSONBin credentials below and click Generate Snippets
  2. In Squarespace, edit the provider's profile page
  3. Add a Code Block where you want the badge to appear
  4. Paste the provider's snippet into the code block and save
  5. That's it — the badge appears automatically when they mark themselves available in the app
